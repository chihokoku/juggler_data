# 最重要事項

私が提供する高設定候補ラベルは、
真の設定情報ではありません。

高設定候補ラベルは

・BB確率
・RB確率
・回転数

などの実績データから推定したものであり、

「実際に高設定だった台」

ではなく

「高設定挙動を示した台」

として扱ってください。

そのため、

・回されなかった高設定台
・発見されなかった高設定台
・サンプル不足で判定不能な台

が存在する可能性があります。

学習時には、

「観測された高設定候補」

と

「真の高設定」

は異なる概念であることを考慮してください。

低回転台を自動的に低設定とみなしてはいけません。

# 目的

私の目的は

・過去の高設定台を当てること

ではなく

・まだ回されていない未来の高設定候補台を予測すること

です。

そのため分析では、

BB確率
RB確率
回転数

そのものではなく、

「店がどのような条件で設定を投入しているか」

を重視してください。

# ラベルに関する注意

高設定候補ラベルは
以下の3段階で扱ってください。

① 高設定候補

観測データが十分あり、
高設定挙動を示した台

② 判定不能

回転数不足などで
高設定・低設定を判断できない台

③ 低設定候補

観測データが十分あり、
低設定挙動を示した台

可能であれば、

「判定不能」

を独立カテゴリーとして扱い、

低設定に含めないでください。

# 分析してほしい内容

1.

高設定候補台に共通する特徴を分析してください。

例

・曜日
・特定日
・角台
・角2
・末尾番号
・島位置
・機種
・X投稿との関連

など。

2.

特徴量重要度を算出してください。

重要度の高い順に並べてください。

3.

高設定候補の投入パターンから、

店がどのような考えで設定配分を行っている可能性があるか推定してください。

例

・角優遇
・末尾投入
・曜日投入
・ジャグラー優遇
・機種単位投入

など。

4.

観測バイアスが結果へ与える影響を評価してください。

具体的に

・稼働率による偏り
・回転数不足による偏り
・常連客の着席行動による偏り

がどの程度考えられるか説明してください。

5.

データ不足で結論が出せない項目については

無理に推定せず

「証拠不足」

と明示してください。

# 注意事項

高設定だった結果
(BB確率、RB確率、回転数)

を説明するモデルではなく、

店がどこへ設定を投入するか

という規則性を学習してください。

また、

未来予測は確率的な推定であり、

完全な予言ではありません。

観測できなかった高設定台が存在する可能性を常に考慮してください。

結果の解釈では

「高設定」

ではなく

「高設定候補の投入確率」

として扱ってください。
